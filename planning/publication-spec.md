# Publication specification

## Approved editorial direction

- Title: Building Mobile Apps with C# 15.
- Subtitle: .NET 11 and .NET MAUI 11: A Windows Developer’s Guide to Android, iPhone, and Tablets.
- Author: John F. Gnazzo. Proposed imprint: DGreatGnazzini Press LLC.
- Audience: basic C#, intermediate desktop/web experience, no mobile background.
- Independent of Mastering Modern C#; no AI instruction or AI application features.
- Public-release phone/tablet application based on johngnazzo.com, provisionally Gnazzo's World.
- Windows-centered MAUI/XAML; Android/iOS coverage; limited supporting backend; real sign-in/MFA and recovery.
- Separate manuscript/code repositories, both currently public.

## Paperback

8 × 10 inches. Black ink, white paper, color cover. Target 750–800 total interior pages and remain within the verified 828-page KDP ceiling. Use a starting inner margin of 0.95 inch for the planned thick volume and outside margin 0.65 inch, then validate binding/readability in a physical proof. KDP's minimum inside margin at 701–828 pages is 0.875 inch.

Body: 11-point Source Serif 4, approximately 14-point leading. Headings: Source Sans 3. Code: 9.5–10-point Source Code Pro, with short lines and complete listings in code repository. Do not reduce code type to conceal overflow.

Each Part and chapter starts a new page (not necessarily a right-hand page). Part openers contain a unique representative grayscale illustration, substantive section introduction, and chapter previews. Each illustration receives a caption/alt description and recorded provenance.

Front matter: half-title, title/copyright pages, optional dedication, acknowledgments, detailed TOC, preface, reader orientation, environment requirements. Back matter: appendices, glossary, references, index, approved bio, companion resources/errata, appropriate notices. Index pagination is finalized after layout.

## Ebook

Reflowable EPUB. Relative typography, semantic headings, navigable TOC, cross-links, alt text, meaningful code formatting, and linked index targets. No mandatory reproduction of paperback page numbers or physical blank pages.

## Status of sample layout

The first PDF specimen tests physical page size, margins, new-page starts, body/code sizes, and a table. It is a typography proof, not publication-ready pages. If the chosen Source fonts are unavailable, label replacements explicitly and do not silently approve them as final. Real app screenshots and the eight final Part illustrations will follow verified app builds and stable section content.
